# 전체 흐름

영상 입력 → 탐지·추적 → 카메라별 주차면 관측 → 매핑·통합 → DB/API → 관제 화면

- perception: 탐지·추적·점유 관측과 입출차 후보
- fusion: 실제 주차면 매핑, 관측 충돌과 가림 처리
- backend: 영상 입력, 저장과 API
- app (PyQt6): 색인·관제·학습 UI 통합
- evaluation: 독립적인 정답과 예측 비교

직전 상태를 유지하는 최종 책임은 fusion에 둡니다. 단일 카메라도 같은 흐름을 사용합니다.
관측 충돌 정책과 동기화 허용 오차는 실제 영상을 검토한 후 확정합니다.
