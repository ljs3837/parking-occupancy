## 주차면 추론 임계값 조정

보도블록 오검출과 실제 주차면 누락을 비교하기 위해 `conf`를 `0.35 → 0.40 → 0.45 → 0.425 → 0.375` 순으로 조정했다.

- `0.45`에서는 보도블록이 검출되지 않았고 실제 주차면도 몇 개 누락됐다.
- `0.425`에서는 직전과 비슷하게 보였다.
- 현재 비교값은 `0.375`다. 보도블록 오검출과 대각선·잘린 주차면 누락 여부는 같은 CCTV 장면에서 확인 후 기록한다.

`conf`는 앱이 추론에서 주차면 후보를 표시할 때 쓰는 임계값이다. 학습할 때는 위 표의 2차 증강 설정을 사용한다.
