# 정답 표시 기준 초안

실제 주차면 ID와 시각 기준으로 정답을 표시합니다.

- 영상·카메라 ID, 시각 또는 프레임, 주차면 ID, 상태, 가림과 판정 근거를 기록합니다.
- 상태는 occupied / vacant / unknown을 사용합니다.
- 확인 불가 상태를 추측해서 vacant로 표시하지 않습니다.
- 다른 영상으로 확인했다면 근거 카메라를 기록합니다.
- 정답의 미확인과 시스템의 직전 상태 유지는 구분합니다.
- 통과 차량과 주차 차량의 시간 기준은 팀에서 확정합니다.
- 큰 차 가림, 중복 CCTV, 통과 차량, 두 칸 걸침, 야간과 비차량 물체를 포함합니다.
- 조정용 영상과 최종 평가용 영상을 분리합니다.

점유 정확도, occupied precision/recall, 입출차 시각 오차와 unknown 비율을 검토합니다.
unknown 정답 제외 규칙과 예측 unknown 처리 방식은 수치 보고 전에 합의합니다.
