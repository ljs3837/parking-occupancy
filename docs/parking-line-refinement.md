# 주차 칸 기하학 보정

AI가 예측한 칸 영역을 네 꼭짓점으로 정리하고, 주변 도색선으로 선택적으로 보정한다.
주차선만으로 새로운 칸을 생성하는 기능은 아니다.

- conservative: approxPolyDP로 사각형에 가까운 영역만 단순화한다.
- enclosing: approxPolyN으로 볼록 윤곽을 네 꼭짓점으로 근사한다. 가림 때문에 오목한 예측을 보완할 수 있으나 실제 경계를 보장하지 않는다.
- 흰색·노란색 도색에서 HoughLinesP로 직선 구간을 찾는다.
- 후보 경계와 방향 차이 12도 이내이며 거리·겹침 조건을 만족하는 선을 강건 피팅한다.
- 선의 근거가 있는 경계가 최소 2개일 때 교점으로 꼭짓점을 보정한다.
- 면적·꼭짓점 이동·볼록성·이미지 범위 조건을 검사하고 원근 사다리꼴을 허용한다.

사각형 필터는 누락을 늘릴 수 있다. snap_lines=False는 네 꼭짓점 정리만 적용한다.
차량 탐지는 변경하지 않는다. 출력 신뢰도는 AI 신뢰도를 그대로 유지한다.

부분 가림 학습은 이미지 일부를 가리되 전체 칸의 정답은 유지한다.
가려진 부분까지 정답이 일관되게 작성되어야 효과를 기대할 수 있다.
실제 차량·나무 가림에 대한 성능은 별도 검증해야 한다.

관련 실험과 재현 명령은 parking-line-experiments.md를 참고한다.
