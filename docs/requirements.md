# 요구사항 초안

## 확정할 항목
- 카메라 수와 배치, 실제 주차면 수
- 영상 해상도·프레임률과 시각 동기화
- 점유·입차·출차 정의와 지속 시간
- 두 칸에 걸친 차량의 대표 주차면 선택 기준
- 목표 정확도와 허용 지연, 상태 유효 시간

## 예외 처리
- 큰 차가 뒤 칸을 가리면 입출차 이력과 다른 카메라 관측을 활용합니다.
- 여러 CCTV의 같은 칸은 같은 실제 주차면 ID를 사용합니다.
- 지나가는 차는 지속 시간과 이동 정보로 점유에서 제외합니다.
- 카메라별 탐지 하나는 주차면 하나에만 할당합니다.
- 그림자·야간과 카트·콘·눈·쓰레기를 평가에 포함합니다.
- 안 보이는 칸은 직전 상태를 유지하고 다시 보이면 갱신합니다.
- 시작부터 안 보이는 칸은 unknown으로 표시합니다.
